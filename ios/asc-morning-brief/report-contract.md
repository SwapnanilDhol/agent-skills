# Report contract

Write `EXECUTIVE_SUMMARY.md` with these sections:

1. **Executive readout** — ≤5 bullets (growth, revenue, reputation, release, risk)
2. **KPI scorecard** — current / comparison / Δ abs / Δ % for 7d and 28d
3. **Acquisition** — impressions, page views, conversion, first downloads, redownloads, updates, sources, campaigns, CPPs
4. **Engagement and quality** — sessions, retention/cohorts if present, crashes by version, installs/deletes
5. **Monetization** — sales, proceeds, paying users, active subscriptions, SKU mix
6. **Ratings and reviews** — storefront averages, unanswered ≤3★, themes
7. **Release and operations** — App Store state, build, TestFlight, Xcode Cloud
8. **Recommended actions** — ≤5 concrete, evidence-tied
9. **Data health** — failed collectors, stale/partial days, caveats

Cite supporting filenames in parentheses after material claims, e.g.
`(web/overview-current-7d.json)`.

Distinguish:

- Apple web analytics
- App Store Connect public API
- Official Analytics Reports API / TSVs
- Public storefront ratings
